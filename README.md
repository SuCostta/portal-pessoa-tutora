Portal da Pessoa Tutora 🚀

> Uma aplicação corporativa desenvolvida para otimizar o rastreamento, o acompanhamento operacional e a gestão de tutores em programas educacionais de alta escala.

📌 Sobre o Projeto

O **Portal da Pessoa Tutora** nasceu da necessidade de centralizar e automatizar o fluxo de acompanhamento e monitoramento de tutores. O sistema resolve dores operacionais ligadas à descentralização de informações, garantindo mais agilidade para a equipe de gestão, padronização de registros e uma experiência de usuário (UX) fluida e intuitiva para quem está na ponta operando o programa.

🛠️ Tecnologias e Arquitetura

A solução foi construída utilizando uma stack moderna orientada a baixo código com alto poder de customização e automação de fluxos:

* **Plataforma de Desenvolvimento:** AppSheet (para construção rápida de interfaces responsivas e lógica de negócio baseada em dados relacionais).
* **Banco de Dados e Armazenamento:** Google Workspace / Google Sheets estruturado como banco relacional otimizado.
* **Automações e Scripts:** Google Apps Script para rotinas automáticas de disparo de notificações e validações.
* **Versionamento e Documentação:** Git e GitHub (`SuCostta`) para controle de código e documentação técnica.
* **Ambiente de Trabalho:** Windows, VS Code e PowerShell.

📐 Arquitetura da Solução e Fluxo de Dados

1. **Camada de Dados:** Estrutura relacional normalizada para evitar redundâncias e garantir integridade nos cadastros de tutores e históricos de acompanhamento.
2. **Camada de Regras de Negócio (AppSheet):** Configuração de visões baseadas em funções (*Role-Based Access Control*), garantindo que cada usuário visualize apenas o que compete à sua alçada.
3. **Camada de Automação:** Disparos automáticos via Apps Script para otimizar o fluxo de trabalho e reduzir o esforço manual da equipe de coordenação.

✨ Principais Funcionalidades

* **Gestão Centralizada de Perfis:** Cadastro e acompanhamento estruturado do progresso e alocações de cada tutor.
* **Interface Responsiva (UX/UI):** Telas otimizadas para uso rápido em campo ou em sessões de trabalho nos computadores e dispositivos móveis.
* **Tratamento de Dados e LGPD:** Aplicação de boas práticas de segurança e mascaramento de dados sensíveis para garantir conformidade e privacidade.
* **Relatórios Integrados:** Visualização rápida de métricas operacionais para auxiliar na tomada de decisão gerencial.

💡 Aprendizados e Desafios Técnicos

* **Modelagem Relacional em No-Code/Low-Code:** O maior desafio foi estruturar tabelas que pareciam simples em planilhas para se comportarem como um banco de dados relacional robusto no AppSheet, garantindo chaves estrangeiras íntegras e performance fluida.
* **Design de Experiência (UX):** Foco em reduzir o número de cliques para tarefas repetitivas da equipe de tutoria, desenhando jornadas de navegação limpas e intuitivas.
